# Big Rulebook Eval Summary

Each card gets one first answer from the AI. It is scored twice: "no check" takes the answer and the AI's cost as they are; "with check" runs the code check (retry up to 2 times with the broken rules, then the code rejects) and the cost always comes from the code. Cells with two numbers are "no check / with check".

An answer counts as correct when its effects match one accepted answer (in any order the rules allow) and the cost matches. Effects and cost accuracy are over cards that should not be rejected. Accuracy and time exclude cards that ended in an error. Time is model call time (with check includes retries); the 5s Gemini pacing waits are excluded.

Modes: full = core rules + every rule of the size (alphabetical); word = word-overlap RAG (v3); emb = embedding RAG (v6); emb9 = embedding RAG with split pieces and condition pieces dropped (v9). RAG modes give the top 5 rules of that size. Fixed by retry counts retried cards that ended correct.
