# Big Rulebook Eval Summary

Each card gets one first answer from the AI. It is scored three ways. no check: the answer and the AI's cost as they are. retry: the code check (retry up to 2 times with the broken rules, then the code rejects) and the cost comes from the code. reject: no second call; if the first answer breaks a rule the code rejects it, otherwise the code computes the cost. Cells with three numbers are "no check / retry / reject".

An answer counts as correct when its effects match one accepted answer (in any order the rules allow) and the cost matches. Effects and cost accuracy are over cards that should not be rejected. Accuracy and time exclude cards that ended in an error. A first answer that is not valid JSON is an error in no check, and a code rejection in reject (and a failed attempt in retry). Time is model call time (retry includes the extra calls; reject uses the first call only); the 5s Gemini pacing waits are excluded.

Modes: full = core rules + every rule of the size (alphabetical); word = word-overlap RAG (v3); emb = embedding RAG (v6); emb9 = embedding RAG with split pieces and condition pieces dropped (v9). RAG modes give the top 5 rules of that size. Fixed by retry counts retried cards that ended correct. This file is rebuilt from the result files, so rerunning a job never leaves duplicate or half-written rows.
